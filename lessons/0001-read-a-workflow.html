Read a workflow by its data

Your first win: explain one broken connection before running anything.

1. Concept — think function calls

A node performs an operation. Its input and output ports specify data types; a link supplies one node's output to another's input. In Python terms, read a node as a function call and a wire as a passed value. Source: official Nodes guide.

For the standard Stable Diffusion example, distinguish LATENT (a representation in latent space) from IMAGE (pixel data). Denoising takes place in latent space; decoding makes the result viewable. Source: official text-to-image guide.

2. Small workflow — the output stage

KSampler ── LATENT ──▶ VAE Decode ── IMAGE ──▶ Save Image
                            ▲
                            │ VAE
                     Load Checkpoint

This is a fragment of the standard workflow. The sampler's model, prompt conditioning, initial latent, and settings are intentionally outside today's exercise. It is not a complete runnable graph.

VAE Decode needs two inputs: samples accepts LATENT, and vae accepts the VAE model used to decode it. Its output is IMAGE. Save Image expects IMAGE at its images input. Source: VAEDecode and SaveImage definitions.

The decoder performs a learned transformation. Renaming a port or a node does not perform that transformation.

3. Exercise — retrieve before checking

Cover the diagram. Write the data type on each arrow:

KSampler ── ? ──▶ VAE Decode ── ? ──▶ Save Image

Then explain, in one sentence, why the middle node exists.

Check your prediction after answering

LATENT, then IMAGE. VAE Decode uses a VAE model to transform the sampled latent into pixel data. If you only recalled node names, try again using the representations in your explanation.

4. Debugging — repair a broken graph

A colleague removes VAE Decode and tries to connect KSampler directly to Save Image. Name the incompatible types, then describe the repair, including the extra input that the restored decoder requires.

Reveal feedback after proposing a repair

The output is LATENT but the destination expects IMAGE. Restore VAE Decode: connect the sampler output to samples, the checkpoint's VAE output to vae, and the decoder output to Save Image's images. Changing the prompt cannot repair an interface mismatch.

If ComfyUI is already available, find these nodes in the official example and trace the three connections. Follow the first-generation guide to load the example if needed. Otherwise, the paper exercise is sufficient for this lesson.

5. Recap and checkpoint

Read the value flowing through each wire. Identify the transformation required by the next input. This habit will help you place new operations deliberately when we reach illustration and comics workflows.

  2. What two inputs does VAE Decode need, and what does each provide?
  3. If you move Save Image to the left of KSampler without changing any wires, has the data dependency changed? Explain.

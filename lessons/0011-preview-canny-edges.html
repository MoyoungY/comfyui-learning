Lesson 11 / 3 minutes / Inspect before sampling

Preview the control image

Make the fox’s outlines visible before asking ControlNet to follow them.

Recall

What representation does a Canny ControlNet expect? You identified an extracted edge map. Now produce one from your saved illustration.

Build a small preview workflow

Save your current graph and open a separate empty workflow. Add Load Image, the built-in Canny node, and Preview Image. Upload the original 512 × 512 fox illustration through Load Image.

Load Image.IMAGE → Canny.image
Canny.IMAGE      → Preview Image.images

Use low_threshold 0.4 and high_threshold 0.8, the documented defaults for the built-in node. Run once. It outputs white detected edges on black, with IMAGE data type. This preview needs no checkpoint or ControlNet weights. Official node reference.

Check the result

Can you recognize the fox’s silhouette and the tree from the lines? Report what you see. If Canny is missing, report the node-search result before installing extensions. Other Canny implementations may use different threshold scales.

If the outline is mostly missing

Try low_threshold 0.2 and high_threshold 0.4 as an experimental pair, then preview again. Report whether the outline becomes clearer or the map becomes cluttered.

Keep this preview workflow. We will use the same edge output when wiring ControlNet. Ask the agent about any unclear connection or result.

Lesson 08 / 5–8 minutes / Inpainting

Choose where to edit

Add flowers to a small background patch while leaving the fox outside your edit mask.

Concept

Denoise controls sampling strength. A mask selects the area to regenerate. For this workflow, white mask values select editing and black values exclude editing; the editor may display a colored overlay instead. Official inpainting guide.

Build

  1. Save a separate inpainting copy of your workflow. Keep your existing SD1.5 checkpoint and original fox image.
  2. Right-click Load Image and choose Open in MaskEditor. Paint a small patch of background away from the fox, then save the mask. Leave space between the mask and the fox.
  3. Replace ordinary VAE Encode with VAE Encode (for Inpainting). Connect IMAGE to pixels, MASK to mask, and the checkpoint’s VAE to vae.
  4. Connect its LATENT output to KSampler.latent_image. Keep the existing decoder and saver branch. Leave grow_mask_by at 6.

Use the connection checklist.

Checkpoint before running

To add flowers behind the fox, should the mask cover the fox or the background patch? Reply with your answer and whether the wiring is complete.

After feedback: run once

Use positive prompt a watercolor illustration of a small white fox sitting beneath a tree, small yellow wildflowers in the background. Keep negative prompt text, watermark, seed 43 fixed, CFG 10, steps 20, euler, normal. Set denoise to 1.0 for this first test.

This encoder clears masked image content before encoding and attaches a noise mask. We therefore start at 1.0 to regenerate that region instead of carrying over 0.3 from ordinary image-to-image. See VAEEncodeForInpaint source.

Observe and debug

Inspect the patch for flowers, the border for seams, and the fox for unintended changes. The ordinary SD1.5 checkpoint can perform this exercise; specialized inpainting models can improve transitions. The encode/decode round trip may slightly alter unmasked pixels, so this workflow does not guarantee exact pixel preservation. Report what happened before changing settings.

If nothing changes, check that the mask was saved and MASK is connected. If the wrong region changes, inspect mask placement and polarity. Ask the agent any follow-up questions, including if the editor menu differs.

Primary reading: Official inpainting tutorial. Next steps depend on the result; no extra checkpoint download is needed for this first mask exercise.

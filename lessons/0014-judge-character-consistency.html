Lesson 14 / 5 minutes / Evaluate independently

Judge the character

Check whether your combined workflow preserves recognizable character details when the seed changes.

Before running

Choose two visible identifying details in your current fox image, such as a tail-tip marking, ear color, or facial marking. Write them down before viewing the next output. Do not invent details that the image does not show.

Make the pair

  1. Save your working combined graph and seed-43 result. Confirm both LoRA strengths are 0.8 and ControlNet strength is 0.8.
  2. Keep the same checkpoint, prompt, negative prompt, reference image, Canny settings, dimensions, and sampling settings.
  3. Change only the seed to 44, keeping seed control fixed, and run once.

The seed changes sampling noise. The LoRA and ControlNet remain active. Review the official seed parameter reference if needed.

Report three observations

AspectQuestion
StyleDoes each image still read as pixel art?
LayoutDo the fox silhouette and tree placement stay close?
IdentityDid your two chosen identifying details remain?

“Unclear at this resolution” is a valid observation. Shared outlines alone are not enough to judge identity, as you explained earlier.

This is a small test at one composition. Even a successful pair does not establish consistency across different poses, scenes, or comic panels.

Send the three observations to the agent for feedback. If something fails, name the branch you would inspect first. Ask any follow-up questions about uncertain visual details.

Primary reading: KSampler parameter reference. Keep the images and workflow for later comparison.

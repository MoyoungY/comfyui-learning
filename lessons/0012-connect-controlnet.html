Lesson 12 / 5–8 minutes / Spatial guidance

Connect ControlNet

Use your verified edge image to guide a new fox illustration’s layout.

Build

Save a separate copy of the original SD1.5 text-to-image workflow, using direct checkpoint MODEL/CLIP connections without LoRA. Copy in Load Image, Canny, and Preview Image from the edge-preview workflow. Keep Empty Latent Image at 512 × 512, batch 1.

Add Load ControlNet Model and select control_v11p_sd15_canny_fp16.safetensors. Add Apply ControlNet (Advanced), whose inputs include positive, negative, control_net, and image.

Positive text encoder.CONDITIONING → Apply.positive
Negative text encoder.CONDITIONING → Apply.negative
Load ControlNet Model.CONTROL_NET  → Apply.control_net
Canny.IMAGE                       → Apply.image
Apply.positive                    → KSampler.positive
Apply.negative                    → KSampler.negative

These outputs replace the direct text-encoder connections to KSampler. Apply carries control information in the conditioning; it does not output an image. Keep the original MODEL, VAE, empty-latent, and output connections. Official node reference.

Checkpoint

Confirm the six connections. The source image belongs to the Canny branch; KSampler still receives Empty Latent Image. Ask the agent if your node ports differ.

After wiring: compare

Predict whether control enabled or disabled should better follow the fox silhouette. Use positive prompt a watercolor illustration of a small white fox sitting beneath a tree; negative text, watermark. Keep seed 43 fixed, CFG 7, 20 steps, euler, normal, denoise 1.0. On Apply set start_percent 0 and end_percent 1.

  1. Run with strength 0 for a baseline.
  2. Change only strength to 0.8 and run again.
  3. Compare both outputs against the edge map, focusing on fox silhouette and tree placement rather than overall beauty.

0.8 is an experimental starting strength. Report which output follows the reference more closely, or any error. Matching outlines does not establish exact character identity.

Primary reading: Apply ControlNet Advanced inputs and outputs. Ask the agent any follow-up questions before continuing.

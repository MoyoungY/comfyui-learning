Lesson 03 / 5–8 minutes / Wiring only

Complete the sampler inputs

Retrieval: what does CLIP Text Encode produce, and why is that different from its CLIP input?

Concept

The standard SD1.5 sampler takes both positive and negative CONDITIONING. Two instances of the same text-encoding node supply them. The destination port gives each branch its role. Official tutorial.

Empty Latent Image creates a zero-filled latent with the requested dimensions and batch size. Random noise is prepared inside the KSampler sampling path using its seed. Source: EmptyLatentImage and common_ksampler.

Build

Select the installed SD1.5 checkpoint. Keep existing correct connections and add only missing nodes. The complete graph has seven nodes: one loader, two text encoders, one empty latent, one sampler, one decoder, one saver.

  1. Send the loader's CLIP output to both text encoders.
  2. In the encoder connected to positive, enter a watercolor illustration of a small red fox sitting beneath a tree.
  3. In the encoder connected to negative, enter text, watermark. Negative prompting provides guidance rather than a guaranteed exclusion rule.
  4. Add Empty Latent Image, set width and height to 512 and batch_size to 1, and connect its LATENT output to KSampler's latent_image.
  5. Use the nine-connection checklist to verify the whole graph.
Do not run yet. The server was launched in CPU mode. We will choose an available GPU and sampling settings after checking this wiring.

Debugging exercise

A colleague swaps the positive and negative connections. Predict whether the data types still match, and whether the sampling instructions keep their intended meaning.

Feedback after predicting

Both outputs are CONDITIONING, so the types still match. Their roles change because they reach different sampler inputs. A graph can have valid types and still express the wrong intention.

Recap and checkpoint

Check both the port type and its role.

  1. If you rename a text encoder “Negative” but connect it to positive, which role will it serve?
  2. Does Empty Latent Image create the seed-dependent random noise? Where is that prepared?

Reply with your predictions and whether the wiring is complete. Ask the agent any follow-up questions before continuing.

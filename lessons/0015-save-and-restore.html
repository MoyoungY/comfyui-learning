Lesson 15 / 5 minutes / Reuse your work

Save and restore a result

Recover the settings behind a preferred illustration and rerun them on your current server.

Choose and preserve

Choose a preferred fox result; the scarf issue is set aside. Download the original PNG from Save Image or retrieve its original output file. Avoid a screenshot or re-encoded copy, which may lack workflow metadata. Save your current graph before loading another.

Restore

  1. Open a separate workflow and drop the original output PNG on the canvas, not into a Load Image upload field.
  2. If the PNG includes workflow metadata, the graph and settings should load. Official loading instructions.
  3. Check the restored seed and set seed control to fixed. Confirm model selections and the reference image in Load Image.
  4. Export the regular editable workflow JSON as fox-style-layout.json using the workflow menu’s Save/Export action. Labels vary with frontend; use the ordinary workflow format rather than API export for this exercise.
  5. Run once and compare against the chosen PNG. Report whether it looks the same or differs.

What to keep

Keep the output PNG, editable workflow JSON, and original ControlNet reference image together. Record exact model filenames and software versions if moving to another machine. A workflow references dependencies; it does not bundle model weights or the source image.

A successful same-session rerun can reuse cached node results. It verifies usable saved state, not a fresh deterministic computation or identical pixels across different hardware and software.

If restoration fails

If dropping the PNG does not load a graph, report it; workflow metadata may be absent. If Load Image cannot find its source, re-upload the saved reference. Do not change seeds or other settings to fix missing-file errors.

Ask the agent any follow-up questions about the export menu or a mismatch.

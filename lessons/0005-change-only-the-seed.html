Change only the seed

Compare two illustrations to separate prompt guidance from variation in the generated result.

Your prediction

You predicted a different image that still broadly follows the prompt: random noise changes while prompt guidance stays the same. That is the expected behavior. The seed controls noise generation; it does not replace the positive or negative conditioning. Official KSampler reference.

Test

  1. Keep the first image for comparison. Confirm its seed was 42; if unsure, set seed 42 and run a baseline now.
  2. Keep control_after_generate at fixed. Keep the checkpoint, both prompts, dimensions, and every other sampler setting unchanged. Refer to the baseline.
  3. Change only seed to 43, then run once.
  4. Compare the fox’s pose and markings, the tree’s position, and the watercolor appearance.

Feedback checkpoint

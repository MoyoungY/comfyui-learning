Recall

Concept

ControlNet supplies spatial guidance using a control image appropriate to its trained task. Examples include edges, depth, and pose. Our first task will use Canny edges: a map of outlines from the saved fox image. This guides structure without guaranteeing identical character details. Maintainer examples.

Saved fox image → edge extraction → edge image
                                         ↓
                         compatible Canny ControlNet
                                         ↓
                           guided image generation

This is a conceptual flow, not the exact port wiring. We will build the graph after confirming the available model.

Feedback after predicting

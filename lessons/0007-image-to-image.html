Lesson 07 / 5–8 minutes / Image to image

Start from your illustration

Use your preferred fox image as a starting point for variations, a step toward deliberately adapting comic artwork.

Recall and concept

VAE Decode converts LATENT to IMAGE. To start from an image, VAE Encode converts IMAGE to LATENT using the loaded VAE. That latent replaces the empty latent at the sampler input. Primary source: VAEEncode and VAEDecode.

Build a separate copy

  1. Save your text-to-image workflow, then save a separate copy for image-to-image.
  2. Add Load Image and upload your preferred 512 × 512 fox PNG using the node’s upload button. Dropping a generated PNG on the canvas can load its embedded workflow instead.
  3. Add VAE Encode. Connect Load Image.IMAGE to VAE Encode.pixels and Load Checkpoint.VAE to VAE Encode.vae.
  4. Connect VAE Encode.LATENT to KSampler.latent_image, replacing the Empty Latent Image connection. Keep the decoder and its VAE connection.

See the three-connection reference. The prompts, model, and output branch remain as before.

One new control

Lower denoise generally keeps the result closer to the source; higher denoise allows larger changes. These values are not percentages of changed pixels. Official image-to-image guide.

Predict before running

Which should preserve your fox’s pose more closely: denoise 0.3 or 0.7? Reply with your prediction and whether wiring is complete.

After feedback: compare

Use the same original input image for both runs. Keep your white-fox prompt, negative prompt, checkpoint, seed 43 with fixed seed control, CFG 10, steps 20, euler, and normal. Run at denoise 0.3, then change only denoise to 0.7. Compare pose, silhouette, and watercolor appearance to the source. Do not feed the first result into the second run.

If the sampler rejects an IMAGE connection, check that it receives VAE Encode’s LATENT output. If a VAE input is missing, connect the loader’s VAE output to both encoder and decoder.

Report which output stays closer to the original and one visible difference. Ask the agent any follow-up questions about wiring or results.

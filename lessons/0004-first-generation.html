Lesson 04 / 5 minutes / Execute and observe

Your first generation

Turn your wired graph into one saved illustration. This is the execution baseline for later comic and character experiments.

Recall before running

Which node turns the sampler’s LATENT output into IMAGE data?

Set a baseline

Keep your selected SD1.5 checkpoint and existing connections. Use the first-run settings: 512 × 512, batch 1; seed 42, fixed seed control, 20 steps, CFG 7, euler, normal, denoise 1.0. These are starting settings for this exercise, not an optimum to memorize.

The seed controls noise generation; fixed seed control keeps it from automatically changing after the run. Sampler and scheduler specify the sampling method and noise schedule. See the official parameter reference.

Run once

  1. Use positive text: a watercolor illustration of a small red fox sitting beneath a tree.
  2. Use negative text: text, watermark.
  3. Click Queue Prompt / Queue / Run (the label depends on your frontend).
  4. Inspect the image in Save Image and the remote terminal for completion or errors. The first run must load the checkpoint.
Success means an image reaches Save Image and a file is saved. Judge execution separately from whether the fox looks exactly as imagined.

Immediate feedback

If an image appears, report whether it contains a fox, a tree, and a watercolor appearance. If execution fails, send the error text and the node named in it; do not change several settings at once. Recheck connections against the wiring checklist if an input is missing.

Checkpoint

Reply with the node from the recall question and whether generation succeeded. Ask the agent any follow-up questions about unclear steps.

Primary reading: Official first-image instructions. Next, after successful execution: predict and test one change at a time.

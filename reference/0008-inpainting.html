Reference 08

Mask an edit

Load Image.IMAGE    → VAE Encode (for Inpainting).pixels
Load Image.MASK     → VAE Encode (for Inpainting).mask
Load Checkpoint.VAE → VAE Encode (for Inpainting).vae
Encoder.LATENT      → KSampler.latent_image

Keep KSampler → VAE Decode → Save Image and the decoder’s VAE connection.

White mask values select editing; black values exclude editing. Save the mask in the editor. grow_mask_by expands the sampling mask, so leave space around anything you want to preserve.

First exercise: small background patch, grow_mask_by 6, denoise 1.0, existing SD1.5 checkpoint. The inpainting encoder clears masked content; it differs from ordinary VAE Encode. Exact preservation outside the mask requires additional compositing, beyond this exercise.

# Mission: ComfyUI

## Why
Build and adapt image and video generation workflows independently for AI illustration, comics, and consistent characters. Understand how each workflow works well enough to debug it and operate it on a remote GPU server.

## Success looks like
- Explain the data and model dependencies in an unfamiliar workflow.
- Build, run, debug, and modify a small workflow without copying JSON blindly.
- Use image-to-image, LoRA, and ControlNet for deliberate visual changes.
- Evaluate character consistency across comic panels and animation frames.
- Run and troubleshoot workflows on a remote GPU server.

## Constraints
- Python and basic programming experience; research-level deep learning background; GPU and remote Linux experience.
- New to ComfyUI; prior use of AI image generation tools.
- Short progressive lessons: concept → small workflow → exercise → debugging → recap.
- Check understanding before introducing the next topic; prioritize official documentation and primary sources.
- Installation, available models, hardware, and time budget are not yet established.

## Out of scope
- No permanent exclusions stated. Advanced topics are deferred until their prerequisites are demonstrated.

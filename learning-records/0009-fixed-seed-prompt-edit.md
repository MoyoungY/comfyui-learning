# A fixed-seed prompt edit mostly preserved composition in one comparison

The user correctly rejected a guarantee that changing “red fox” to “white fox” at a fixed seed would affect only color, although their explanation did not yet establish the conditioning mechanism. After the suggested comparison, they reported that color changed while pose and position did not change much. This establishes an observed mostly localized edit in this pair, not a general guarantee of composition or character-identity preservation; next assess why keeping the seed fixed helps isolate a prompt edit.

# Enabled LoRA produced stronger pixel-art style

Following the proposed same-prompt, fixed-seed comparison with both LoRA strengths at 0 versus 0.8, the user identified 0.8 as producing the stronger pixel-art style. This supports successful adapter use by user report and recognition of its visible contribution beyond the prompt alone. Exact settings and images were not independently inspected; the comparison does not isolate MODEL versus CLIP effects or demonstrate character consistency.
